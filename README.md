# Dark Timeline Planner v11 Patch

## 変更内容
- 今日のメモ欄を調整
  - 入力欄内の例文プレースホルダーを削除
  - メモ保存/追加ボタンを入力欄の横幅に合わせて配置
- 集中タブに 52/17 ルールタイマーを追加
  - 52分作業 → 17分休憩を自動切替
- プロジェクト日割りに「文字数ベースの日割り」を追加
  - 目標文字数
  - 開始日/締切日
  - バッファー率
  - 作業しない曜日
  - 1日あたり文字数と累計文字数を出力

## 使い方
v10適用済み環境へ、このZIP内のファイルを上書きアップロードしてください。
既存の app.js / style.css / v10_patch.js / v10_patch.css / アイコン類は残してください。
