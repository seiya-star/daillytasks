# Dark Timeline Project Planner

黒背景・シンプル・目に優しいタイムライン型プランナーです。
長いプロジェクトを、バッファー込みで日割りタスクに自動分割できます。

## 主な機能
- 今日のタイムライン
- 予定 / ToDo / メモ
- プロジェクト日割り自動生成
- バッファー日・提出日生成
- 作業しない曜日指定
- 1日の最大作業時間チェック
- 再計算
- 集中タイマー
- JSONバックアップ / 復元
- iCalendar出力
- PWA / オフライン対応
