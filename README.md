# Dark Timeline Clean v14

既存機能を残しつつ、過去の差分パッチ方式をやめて、単一のシンプルなアルゴリズムで再構成した版です。

## 方針
- v10〜v13 のパッチ積み重ねを廃止
- index.html / style.css / app.js / sw.js のみで完結
- タブ、描画、保存、カレンダー、集中タイマー、文字数ベース日割りを一本化

## 機能
- 今日タイムライン
- 予定 / ToDo / 曜日タスク
- 日付カレンダー、祝日、日曜色分け
- 今日のメモ、メモスタック
- 集中タブ 25/5、52/17、ホワイトノイズ
- 文字数ベースの日割り、結果をカレンダーへ追加
- JSONバックアップ/復元
- iCalendar出力

## 反映
過去の patch ファイルは不要です。リポジトリをこのZIPの中身で置き換えてください。
